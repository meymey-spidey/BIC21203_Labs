## How to Run
⚠️ **Question 2 requires a local server** because `fetch()` on `file://` is blocked by CORS.

1. Clone repo.
2. Open terminal in the folder.
3. Run a local server:
   - VS Code Live Server extension → click "Go Live"
   - OR: `python -m http.server 5500`
4. Open `http://localhost:5500/books.html`
5. Open `http://localhost:5500/jquery-dom.html`
